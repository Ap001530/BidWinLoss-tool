SHAP vs. the BU's documented hypotheses

The BU's feature hypotheses document ranked features by expected importance before any modelling. This compares that rank to where SHAP actually places each feature after training. Because the synthetic data's weights were themselves set from these hypotheses, agreement is expected and is not independent confirmation — the interesting result is where the two ranks diverge, which reflects noise, interaction effects, or class imbalance the model picked up that a flat reading of the hypotheses would not predict.
